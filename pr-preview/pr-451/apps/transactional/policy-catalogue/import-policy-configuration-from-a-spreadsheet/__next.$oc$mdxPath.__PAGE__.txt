# Import policy configuration from a spreadsheet

Stage policy-register rows from an Excel workbook, review the import counts and push the staged rows into the platform configuration.

## Who can do this?

The app requires portal access to stage and push policy configuration. Follow the applicable policy or SoD approval process before using **Push Now**.

## What do I need before I start?

- The register/entity to import and its approved configuration values.
- An Excel workbook with the columns from that entity's template. Supported extensions are **.xlsx**, **.xlsm** and **.xls**.
- Confirmation that the entity is offered in the import selector; violation logs and some exception registers are excluded from spreadsheet import.

## How do I complete the task?

1. Open **Policy Catalogue** and select **Import Spreadsheet**.
2. In the dialog, choose the **Entity** to import and select **Download Template**.
3. Fill the workbook using its supplied column headings and values. Check codes carefully; existing codes cannot be changed.
4. Select **Choose File**, choose the completed workbook, then select **Upload**.
5. Review the **Staged** and **Skipped** counts. Uploading stages rows; it does not yet make them live.
6. After confirming the workbook and staged change are intended, select **Push Now**. Review the created and updated counts.
7. Close the dialog, open the corresponding register and run **Refresh Entries** to verify the live configuration.

## How do I know it worked?

The dialog reports staged and skipped rows after upload, then created and updated rows after **Push Now**. A fresh **Refresh Entries** shows the resulting live values.

## What if I can’t complete it?

- If the file is rejected, choose a non-empty workbook with an **.xlsx**, **.xlsm** or **.xls** extension.
- If rows are skipped, check the workbook values, required names, code uniqueness and the staged/skipped summary before retrying.
- If an entity is not offered, use its catalogue entry editor if it is writable; some registers are intentionally excluded or read-only.
- Do not assume **Upload** changes live configuration. Use **Push Now** only after review; it applies the staged rows for the selected entity.
