# Import global reference data

Stage an approved spreadsheet for a supported global reference-data entity, then push the staged rows into the platform catalogue.

## Who can do this?

The utility requires portal access and has no narrower app-level role restriction. Because these records affect platform-wide configuration, follow the platform data-governance process before pushing changes.

## What do I need before I start?

- The supported **Entity** to update and the approved values for it.
- A non-empty Excel workbook using that entity's template. The importer accepts **.xlsx**, **.xlsm** and **.xls** files.
- The authoritative code or natural key for each row. Existing identifiers are used to match rows and should not be repurposed.

## How do I complete the task?

1. Open **Global App** and select **Import Spreadsheet**.
2. Choose the **Entity** from the supported list, then select **Download Template** for that entity.
3. Fill the template using its supplied column headings and reference values.
4. Choose the workbook and select **Upload**. Review the **Staged** and **Skipped** counts; uploaded rows are not live yet.
5. After confirming the entity and workbook are correct, select **Push Now**.
6. Review the created and updated counts, then open the corresponding section in **Global App** or its owning app to verify the applied values.

## How do I know it worked?

The upload reports staged and skipped counts; **Push Now** reports created and updated counts. The target global entity shows the resulting reference values.

## What if I can’t complete it?

- If the file is rejected, use a non-empty Excel workbook with a supported extension and the selected entity's template.
- If no rows are staged or rows are skipped, review the required key, name and reference values in the workbook before retrying.
- If the entity is not offered in the selector, this utility does not import it; use the owning app or its approved setup process.
- If the platform catalogue entry for the entity is missing, contact the platform administrator rather than creating a registry row here.
- Uploading alone does not apply the data. Use **Push Now** only after reviewing the staged import.
