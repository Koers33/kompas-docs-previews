# Validate mapping coverage before go-live

Check whether a company’s active financial nodes and accounting definitions have the mapping coverage required for go-live.

## Who can do this?

Users who can open the Financial Node Account Mappings app can run **Validate All Mappings** on a saved mapping. Access to the app still depends on assigned roles and portal access.

## What do I need before I start?

- A saved mapping associated with the company you want to validate.
- The company’s active financial nodes and accounting setup ready for review.

## How do I complete the task?

1. Open **Financial Node Account Mappings** and select a saved mapping for the company.
2. Select **Validate All Mappings**.
3. Review the result, including **Missing Count**, **Total Mappings**, **Ready For Go-Live** and any listed missing mappings or definition gaps.
4. For each missing node, create or correct its account mapping. Resolve definition gaps in the relevant accounting configuration.
5. Run **Validate All Mappings** again after the corrections.

## How do I know it worked?

The validation reports that the company is ready for go-live with zero missing mappings and zero definition gaps. A non-ready result lists what remains to be resolved.

## What if I can’t complete it?

- If **Validate All Mappings** is unavailable, ensure the mapping is saved; the action does not run on a new draft.
- If a node is reported missing, check that it has an active mapping for the company.
- If accounting definitions are reported incomplete, resolve the definition in the configuration app responsible for that entry before validating again.

## What should I do next?
