# Register or update a governed configuration area

Add or maintain the catalog record that describes how a company’s configuration area is governed.

## Who can do this?

The app requires portal access and has no additional service-level role restriction. Follow your organization’s governance process when changing the approval level for a register.

## What do I need before I start?

- The configuration area the register represents and its unique **Register Code**.
- The **Register Category**, required **Approval Level** and review interval.
- The description users need to identify what the register governs.

## How do I complete the task?

1. Open **Config Data**. Select **Create** for a new register, or open an existing register to update it.
2. Enter **Register Code** and **Register Name**. Choose **Register Category** and **Approval Level** from their lists.
3. Add or update the description and **Review Cycle (Days)**. Leave **Is Active** on while the register remains in use.
4. Save the register. Its code must be unique for the company.
5. To retire a register, switch **Is Active** off and save it; do not try to delete the record.

## How do I know it worked?

The register appears in the catalog with the intended category, approval level, review cycle and active state. Open it to confirm the description and governance details.

## What if I can’t complete it?

- If saving reports a missing field, complete **Register Code**, **Register Name**, **Register Category** and **Approval Level**.
- If the register code is already in use, choose another unique code.
- If deletion is refused, retire the register by turning **Is Active** off.
