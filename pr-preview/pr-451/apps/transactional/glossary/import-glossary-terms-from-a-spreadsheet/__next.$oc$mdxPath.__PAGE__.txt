# Import glossary terms from a spreadsheet

Bulk-add new glossary entries from an Excel workbook and check how many rows the importer accepted or skipped.

## Who can do this?

The app requires portal access and the roles assigned by your administrator. Review the shared terminology before importing it.

## What do I need before I start?

- A spreadsheet of new terms; the importer accepts **.xlsx**, **.xlsm** and **.xls** files.
- A unique **Term** for each row. A blank term is skipped, and a term already in Glossary is skipped rather than updated.
- Any existing classification values and term details to add after import. The downloadable template does not include the **Category**, **Scope** or **Audience Level** columns.

## How do I complete the task?

1. Open **Glossary** and select **Import Spreadsheet**.
2. In **Import Glossary Spreadsheet**, select **Download Template** and fill one row per new term. Keep the template's column headings and include the term and definition details.
3. Select **Choose File**, choose the completed workbook, then select **Upload**.
4. Read the completion message's **imported** and **skipped** counts.
5. Open the imported terms in Glossary, add their category, scope and audience level, and verify definitions and context.

## How do I know it worked?

The completion message reports the number of imported and skipped terms. Search for imported terms in the Glossary list and open them to verify the saved content and classifications.

## What if I can’t complete it?

- If the file is rejected, choose a non-empty Excel workbook with an **.xlsx**, **.xlsm** or **.xls** extension.
- If terms are skipped, check for blank terms, duplicates already in the glossary and invalid category/scope/audience codes if you added those columns yourself.
- Import only adds new terms; it does not update an existing term. Correct an existing record directly in [Glossary](./add-or-update-a-glossary-term).
- The completion message shows counts; detailed skipped-row explanations are not displayed in the dialog. Review and correct the workbook before retrying.
