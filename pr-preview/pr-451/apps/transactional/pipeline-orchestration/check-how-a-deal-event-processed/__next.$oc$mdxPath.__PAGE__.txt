# Check how a deal event processed

Find an execution for a deal event, read its final status and failure details, and pass the correlation reference to the owner of the follow-up work.

## Who can do this?

Users with portal access can read execution records. The app is a monitoring view; it does not let users restart or edit a run.

## What do I need before I start?

- The approximate event time or a **Correlation ID**, if available.
- The deal event and company involved, if known.
- Whether the run was a scenario or live execution.

## How do I complete the task?

1. Open **Pipeline Orchestration** and filter by **Execution Status**, **Started At**, **Completed At** or **Scenario Mode**.
2. Open the matching execution and note its **Correlation ID**, status and timestamps.
3. If the run did not complete, read **Failure Category**, **Failure Step** and **Failure Code**. Review the domain results or execution traces available for the run.
4. Share the correlation ID and failure details with the team that owns the deal or its company/instrument configuration.

## How do I know it worked?

You have identified whether the run completed, was rolled back, failed or was treated as idempotent, and captured its correlation ID and any failure details for follow-up.

## What if I can’t complete it?

- If no row appears, clear filters; the app cannot create execution records.
- If a run is **ROLLED_BACK** or **FAILED**, use its failure fields and correlation ID with the [registered 5xx error reference](/reference/error-codes/block-5xx-res).
- If an expected domain did not run, review the company's matrix in [Company Instrument Effects](/apps/transactional/company-instrument-effects).
- This app has no user-facing retry control. Do not treat scenario replay as a production reprocessing action.

## What should I do next?

Check the owning result in [Journal Entries](/apps/transactional/journal-entries), [Cash Account Balances](/apps/transactional/cash-account-balances) or [Evidence](/apps/transactional/evidence), as applicable.
