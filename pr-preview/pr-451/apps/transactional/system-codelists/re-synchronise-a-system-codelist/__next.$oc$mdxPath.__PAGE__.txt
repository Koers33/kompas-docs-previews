# Re-synchronise a system codelist

Pull current system picklist values into the catalogue view, or push reviewed entry changes back to the live list.

## Who can do this?

Users with portal access can refresh and update system codelist entries. Coordinate changes with the platform owner because technical lists may be used by multiple screens or integrations.

## What do I need before I start?

- The **Entity Name** of the codelist.
- A decision whether to pull live values into the view or apply reviewed staged values.
- If pushing, the intended codes, names, descriptions and active states.

## How do I complete the task?

1. Open **System Codelists** and select the relevant list.
2. Run **Refresh Entries** to load the current live values. This replaces the entries currently shown.
3. To publish staged changes, review the entries and run **Update Entries**.
4. Reopen the list and confirm it reflects the direction you chose.
5. Verify the changed value in the screen or configuration that uses it.

## How do I know it worked?

After refresh, the view matches the live list. After update, the live system list contains the reviewed values and active states.

## What if I can’t complete it?

- Refresh replaces the current view with the live list; do not refresh while you need to preserve staged edits.
- If an update fails, correct the duplicate or missing code/name reported by the app before retrying.
- System list definitions themselves cannot be created or deleted in this app.
