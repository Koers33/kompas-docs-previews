# Create a project and add phases

Set up a client project and its dated phases so project items and requests can be linked to the right work.

## Who can do this?

Treasury users can create and manage projects. Client users linked as **Project Manager** can manage their client's projects; a **Project Viewer** can read only.

## What do I need before I start?

- A client and an active counterparty relationship for the counter party.
- A configured **Project Type**.
- A unique **Project Code**, description, project start date and project end date.
- The phase categories, names and dates to add after the project is saved.

## How do I complete the task?

1. Open **Projects** and select **Create**.
2. Choose the **Client**, **Counter Party** and **Project Type**. Enter **Project Code**, **Project Description**, **Project Start Date** and **Project End Date**.
3. Save and activate the project draft. The **Project Phase**, **Client Request**, **Project Notes** and **Documents** sections become available after the save.
4. In **Project Phase**, create each phase with its **Project Phase Category**, **Project Phase Name** and dates.
5. Save and verify the phases appear under the project. The platform seeds default risk percentage bands for a client when its first project is created and no bands exist yet.

## How do I know it worked?

The project appears with its client, counter party, type and dates. Its phases appear in the **Project Phase** section, and project items can now be linked to those phases.

## What if I can’t complete it?

- If **Counter Party** is missing, confirm an active relationship exists between that organization and the client in Business Partners.
- If the project code already exists, choose a different unique code.
- If a phase name is duplicated within the project, choose a distinct name.
- Phase dates must fall within the project dates, and a phase cannot end before it starts.
- Project records cannot be deleted; correct their details or follow your approved project-retirement process.
