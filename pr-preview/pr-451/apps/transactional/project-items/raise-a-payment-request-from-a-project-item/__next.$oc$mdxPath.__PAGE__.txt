# Raise a payment request from a project item

Create a payment-request draft from a saved buy-side project item and continue completing the payment details in Payment Requests.

## Who can do this?

Treasury users can create payment requests from items. A Client user linked as a **Project Manager** can manage items for that client; **Project Viewer** access is read-only.

## What do I need before I start?

- A saved project item for the correct client and project.
- **Transaction Side** set to **Buy**. Payment requests cannot be created from a sell-side item.
- The applicable **Payment Option**.

## How do I complete the task?

1. Open **Project Items** and select the saved buy-side item.
2. Select **Create Payment Request** and choose the **Payment Option**.
3. Review the payment-request draft that opens in **Payment Requests**. It carries the client, supplier, project, project item, amount and buy currency; the status starts as **Draft**.
4. Complete the remaining invoice, tax, bank account, payment condition and due-date details required for the request.
5. Save and continue the finalisation and sending steps in **Payment Requests**.

## How do I know it worked?

The payment request appears as a draft linked to the project item, and the item's status changes to **In For Payment**. The request still needs its required details and normal payment-request processing.

## What if I can’t complete it?

- If the action is missing or no draft opens, confirm the item is saved and its **Transaction Side** is **Buy**.
- If required payment details are blank, complete them in [Payment Requests](/apps/transactional/payment-requests); the item action creates a draft and does not submit it.
- If the payment option is missing, ask the owner of the platform payment-option list to configure it.
