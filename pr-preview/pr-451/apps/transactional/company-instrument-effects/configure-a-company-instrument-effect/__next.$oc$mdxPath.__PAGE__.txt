# Configure a company instrument effect

Set which processing steps apply to a company, instrument, lifecycle event and acting-capacity combination.

## Who can do this?

The app requires portal access and the roles assigned to your account. The service adds no further role restriction for these records; ask your administrator if the app or editing controls are unavailable.

## What do I need before I start?

- The company, instrument, lifecycle event and acting capacity this effect row should cover.
- The processing switches and execution order approved for that combination.
- If **Accounting** will run, the financial node, accounting event and ledger settings needed by the posting configuration.

## How do I complete the task?

1. Open **Company Instrument Effects**. Select **Create** for a new row, or open the existing row for the combination you need to change.
2. Set **Company**, **Instrument**, **Lifecycle Event** and **Acting Capacity**. These identify when the row applies.
3. In **Phase 1 Engines** and **Phase 2 Engines**, switch on only the processing steps required for this combination. Set **Engine Execution Order** where needed.
4. If **Accounting** is enabled, complete the accounting configuration, including **Financial Node**, **Accounting Event** and **Ledger**.
5. Check **Effective From**, **Active** and **Mandatory Row**, then save. Effect rows cannot be deleted; switch **Active** off to retire one.
6. If accounting is enabled, use [Preview posting resolution for an instrument effect](./preview-posting-resolution-for-an-instrument-effect) before relying on the posting setup.

## How do I know it worked?

The saved row shows the intended company/instrument/event/capacity combination, enabled processing steps and active state. The list columns summarize whether projected cash flow, near-cash, accounting, settlement and evidence steps are enabled.

## What if I can’t complete it?

- If the row does not appear for an event, check that **Company**, **Instrument**, **Lifecycle Event** and **Acting Capacity** match the event and that **Active** is on.
- If the row cannot be saved, complete the required **Engine Execution Order** and any fields required by the selected accounting settings.
- If accounting is enabled but mappings may be missing, run **Preview Posting** and resolve the reported mapping through **Financial Node Account Mappings** or **Treasury Account Master**.
- If you cannot edit the row, ask your administrator to check your portal access and assigned roles.

## What should I do next?

Run **Preview Posting** for accounting rows, then review the resulting processing in the relevant app when the lifecycle event occurs.
