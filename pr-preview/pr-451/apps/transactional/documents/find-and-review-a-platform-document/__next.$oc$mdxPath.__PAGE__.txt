# Find and review a platform document

Locate an uploaded file across supported app areas, inspect its classification and details, and open the attachment.

## Who can do this?

Access is determined by role and the record’s client relationship. Treasury users can read documents broadly; Client users see only records in their permitted client scope. Documents attached to FEC transactions are outside the client document grant.

## What do I need before I start?

- A clue about the document: its type, source record, file name, or approximate upload time.
- Access to the source record if you need to verify where the file was uploaded.

## How do I complete the task?

1. Open **Documents** and choose the relevant table view, such as **Projects**, **Business Partners**, **Payment Requests** or **Project Items**.
2. Filter by **Document Type** or search the visible list using the details you know.
3. Open the matching row and review **Document Number**, **Document Classification**, **Document Type**, **File Name**, **Note** and **Created At**.
4. Open **Attachment** to view or download the file.

## How do I know it worked?

The record and its attachment correspond to the file you were looking for. The document’s classification and creation time are visible on the record.

## What if I can’t complete it?

- If no row appears, clear **Document Type** and switch to **All**; confirm the source app supports this document list.
- If the file is missing from Documents, open the source record and check whether the file was uploaded there. Uploading or replacing a file must be done in that source app.
- If your list is shorter than expected, check your role and the relationship between your client account and the record.

## What should I do next?

Continue the work in the app that owns the source record.
