# Re-synchronise a system master-data list

Pull current Color Names or Item Categories from the live list into the catalogue view, or push reviewed entry changes back to the live list.

## Who can do this?

Users with portal access can refresh and update entries. Coordinate pushes with the owner of the platform list because those values can be shared across screens.

## What do I need before I start?

- The **Entity Name** of the Color Names or Item Categories list.
- A decision whether to refresh from the live list or apply the entries currently shown.
- If pushing, reviewed codes, names, descriptions and active states.

## How do I complete the task?

1. Open **System Master Data** and select the list.
2. Run **Refresh Entries** to pull the current live entries into the catalogue view. This replaces the entries currently shown.
3. To push displayed changes, review the entries and run **Update Entries**.
4. Reopen the list and verify it shows the live values after the operation.
5. Check the screen that consumes the list if you need to confirm a value is offered there.

## How do I know it worked?

After refresh, the catalogue mirrors the live list. After update, the reviewed changes are available to screens that use the list.

## What if I can’t complete it?

- Refresh replaces the current view with live data; do not run it while you need to preserve staged edits.
- If update fails for a missing or duplicate code/name, correct the entry before retrying.
- A list definition cannot be created or deleted here; contact the platform administrator if the expected list is absent.

## What should I do next?
