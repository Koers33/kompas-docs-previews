# Add, correct or retire a system master-data value

Maintain a value in the platform's Color Names or Item Categories reference list.

## Who can do this?

The app requires portal access and has no additional role restriction. Coordinate changes to shared system data with the platform owner.

## What do I need before I start?

- The list to update: **Color Names** or **Item Categories**.
- The approved **Code**, **Name** and description for the value.
- Confirmation whether the value should be active or retired.

## How do I complete the task?

1. Open **System Master Data** and choose the relevant list.
2. Open its **Entries** section and add a value or edit an existing entry.
3. Enter the required **Code** and **Name**. To retire a value, switch **Is Active** off rather than deleting it.
4. Save and, if the list is staged, use **Update Entries** to push the values to the live list.
5. Reopen the list and verify the code, name, description and active state.

## How do I know it worked?

The entry appears in the list with its saved values. The platform screens that use Color Names or Item Categories can read active values from the live list.

## What if I can’t complete it?

- If code or name is missing, complete both before saving.
- Codes are permanent and duplicate codes are refused; correct the display name or description rather than changing a code already in use.
- If the list row is missing, contact the platform administrator; list definitions cannot be created here.
- Entries cannot be deleted. Switch **Is Active** off to retire one.

## What should I do next?

Verify the value in the screen or list that uses it.
