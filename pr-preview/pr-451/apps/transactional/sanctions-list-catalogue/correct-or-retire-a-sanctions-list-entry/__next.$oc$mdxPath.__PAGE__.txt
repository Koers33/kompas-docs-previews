# Correct or retire a sanctions list entry

Update a sanctions list's name, authority or effective date, or deactivate a list that should no longer be used.

## Who can do this?

Users with portal access can read, create and update catalogue entries. Follow your sanctions-policy owner and compliance procedure before changing which lists are in force.

## What do I need before I start?

- The **List Code** and the current list record.
- The official **List Name**, **Source Authority** and **Effective Date** from the source authority.
- Approval to activate or retire the list.

## How do I complete the task?

1. Open **Sanctions List Catalogue** and find the row by **List Code** or active state.
2. Open the row. Correct **List Name**, **Source Authority** or **Effective Date** as needed; the **List Code** cannot be changed after creation.
3. To retire the list, switch **is Active** off instead of deleting the record.
4. Save and activate the draft.
5. Reopen the row and confirm the list details and active state.

## How do I know it worked?

The list shows the intended code, name, authority, effective date and active state. Inactive rows remain in the catalogue for reference but are no longer active screening-list configuration.

## What if I can’t complete it?

- If the list code is wrong, it is immutable after creation; create a separate entry with the correct code rather than trying to change the existing key.
- If the save control is unavailable, confirm the row is in a draft or editable state and check your portal access.
- If you need to remove a list from use, deactivate it; catalogue rows cannot be deleted.

## What should I do next?

If several list entries need updating, use [Import sanctions lists from a spreadsheet](./import-sanctions-lists-from-a-spreadsheet).
