# Import sanctions lists from a spreadsheet

Stage multiple sanctions-list entries from an Excel workbook and explicitly apply the staged rows to the catalogue.

## Who can do this?

Users with portal access can import and update catalogue entries. Review the source authority and effective date before applying a list change.

## What do I need before I start?

- The approved list codes, names, authorities, effective dates and active states.
- A non-empty **.xlsx**, **.xlsm** or **.xls** workbook using the catalogue template.
- Confirmation that this is the spreadsheet you intend to stage; a new upload replaces the previous staged import.

## How do I complete the task?

1. Open **Sanctions List Catalogue** and select **Import Spreadsheet**.
2. Select **Download Template** and fill the expected columns: **List Code**, **List Name**, **Source Authority**, **Effective Date** and **is Active**.
3. Choose the completed workbook and select **Upload**.
4. Review the **Staged** and **Skipped** counts. Rows without a list code are skipped; existing list codes are matched for update rather than duplicated.
5. After reviewing the spreadsheet and counts, select **Push Now** to apply the staged entries. Alternatively, use **Update Entries** from an open record to apply the staged set.
6. Review the created/updated counts and reopen the catalogue rows to confirm the result.

## How do I know it worked?

The push reports how many rows were created and updated. The catalogue shows the resulting values; the **List Code** remains unchanged on existing rows.

## What if I can’t complete it?

- If the file is rejected, select a non-empty Excel workbook with one of the supported extensions.
- If rows are skipped, check the staged count and workbook for blank **List Code** values.
- If an existing code needs a correction, edit the existing entry's name, authority or date; importing does not overwrite its code.
- If the master-data catalogue entry is missing, contact the platform administrator; this app cannot create its own catalogue registration.
- If the push reports errors, inspect the counts and correct the source workbook before staging it again.
