# Maintain the shared financial node set

Add or correct a platform-wide financial node definition, or retire one that should no longer be offered to companies.

## Who can do this?

The app requires portal access and the roles assigned by your administrator. Follow the platform's accounting configuration process because changes affect the shared node vocabulary.

## What do I need before I start?

- The **Node Code** and **Node Name**.
- The approved **Category**, **Normal Balance** and **IAS 7 Classification**.
- The **Permitted Paths** and description, if relevant.
- Confirmation that the change belongs in the shared standard set, rather than only in one company's setup.

## How do I complete the task?

1. Open **Global Standard Financial Nodes** and find the node by **Node Code**, category or active state.
2. Select **Create** for a new definition, or open the existing node to correct it.
3. Complete **Node Definition**. **Node Code**, **Node Name**, **Category**, **Normal Balance** and **IAS 7 Classification** are required; choose category and classification values from their lists.
4. Save and activate the draft through the app's normal save flow. For a node that should no longer be offered, switch **Active** off and save instead of deleting it.
5. Review the list to confirm the code, classifications and active state.

## How do I know it worked?

The shared node list displays the saved **Node Code**, **Node Name**, **Category**, **Normal Balance**, **IAS 7 Class**, **Permitted Paths** and **Active** state. Retired nodes remain listed as inactive.

## What if I can’t complete it?

- If the save names a missing field, complete the required node code, name, category, normal balance or IAS 7 classification.
- If a classification is not offered, it must be added to the platform's master-data list by its owner; it cannot be typed as a new option here.
- If delete is refused, switch **Active** off instead.
- For a node used by only one company, use [Company Standard Financial Nodes](/user-guides/company-standard-financial-nodes), not this shared catalogue.

## What should I do next?
