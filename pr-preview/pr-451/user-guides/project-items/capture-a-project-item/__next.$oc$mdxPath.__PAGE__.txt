# Capture a project item

Record a unit of client project work so it can be tracked, discussed and taken forward into a request or payment request.

## Who can do this?

Treasury users can create and manage project items. A Client user linked to the client as **Project Manager** can also manage them; a **Project Viewer** can read but not create or change items.

## What do I need before I start?

- The **Client**, saved **Project** and **Project Phase**.
- The client's configured **Project Item Type**, **Project Item Category**, **Payment Group** and **Counter Business Partner**.
- The item description, **Item Target Date**, **Confidence Percentage**, amount and transaction side, as applicable.
- For foreign exchange, the symbol and a **Forex Required Date** that is a business day.

## How do I complete the task?

1. Open **Project Items** and select **Create**.
2. Choose the **Client**, then the **Project** and **Project Phase**. Select the client/project-specific type, category, payment group and counter business partner.
3. Enter the item description, target date, confidence and applicable amount, transaction side and forex details. If **Need Forex** is off, the forex required date is cleared; if it is on, choose a trading day.
4. Add **Notes** or **Documents** if the work needs discussion or supporting files.
5. Save and activate the draft. The platform assigns the **Reference Number** when it creates the item.
6. Reopen the item and verify its **Item Status**, reference number and project details.

## How do I know it worked?

The saved item appears in the project's phase with an assigned reference number and item status. Its Notes and Documents sections are available for follow-up.

## What if I can’t complete it?

- If a value is missing, check the client-specific lists in [Projects Master Data](/user-guides/project-masters).
- If the forex required date is refused, choose a weekday not listed in [Non Trading Dates](/user-guides/non-trading-dates).
- If the project, client or confidence field is immutable after creation, correct the relevant source configuration or create a new item rather than trying to move the saved item.
- If no create control appears, confirm the item is not an unsaved draft and that your relationship grants Project Manager access.
