# Raise a client request from a project item

Start a client request from a saved project item so the request draft carries the item's project, client, amount and transaction context.

## Who can do this?

Treasury users can create requests from project items. Client users need a **Project Manager** relationship to the relevant client; **Project Viewer** access is read-only.

## What do I need before I start?

- A saved project item with its project, client, item type and category.
- A configured symbol and transaction side if the item represents a currency pair.
- The request type the Treasury team should answer.

## How do I complete the task?

1. Open **Project Items** and select the saved item.
2. Select **Create Request** and choose a **Request Type** from the value help.
3. Review the request draft opened in **Requests**. It carries the client, project, amount, currency pair, transaction side, item reference and other available context from the item.
4. Complete any request-type details that are still required, then save the draft.
5. In **Requests**, finalise the details and select **Send Request** when it is ready for Treasury to respond.

## How do I know it worked?

The new request appears in **Requests** as an **Open** draft with the originating project item references. After it is finalised and sent, its status becomes **Requested** and it appears in the unanswered-request views.

## What if I can’t complete it?

- If **Create Request** is unavailable, save and activate the project item first, or confirm your Project Manager access.
- If the request draft is missing a currency pair or amount, check the source item’s symbol, transaction side and amount.
- Creating the draft does not send it. Complete required fields and **Finalised** in Requests before selecting **Send Request**.

## What should I do next?
