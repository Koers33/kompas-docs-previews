# Map a financial node to a general ledger account

Link a company’s active financial node and accounting path to the treasury and general ledger accounts that should receive its postings.

## Who can do this?

Users with portal access and the assigned roles can create or update mappings. **Approve GL Mapping** is limited to the Treasury role; the other mapping actions have their own status and account-type conditions.

## What do I need before I start?

- An active **Company Financial Node** for the company.
- The **Accounting Path** and **Leg Role** for the posting you are mapping.
- The matching **Treasury Account** and **General Ledger Account**, with an account type compatible with the node category.

## How do I complete the task?

1. Open **Financial Node Account Mappings** and select **Create**.
2. Choose the **Company**, **Company Financial Node**, **Accounting Path** and **Leg Role**.
3. Choose the **Treasury Account** and compatible **General Ledger Account**.
4. Set the effective dates and any required mapping details, then save the mapping.
5. Review **Mapping Status** and **Active** on the saved record. If you change the account on an existing mapping, the old mapping is superseded and a new effective-dated mapping is created.

## How do I know it worked?

The mapping shows the intended company node, path, leg role and accounts. **Mapping Status** and **Chain Preview** show whether the mapping is linked and how the account chain resolves.

## What if I can’t complete it?

- If the node already has an active mapping, open and update that record rather than creating a second active mapping.
- If the account is inactive or its type does not fit the node category, select an active compatible general ledger account.
- If the same account is mapped to another node, review the duplicate warning before proceeding.
- Mapping rows cannot be deleted; correct the mapping or follow its status workflow instead.

## What should I do next?
