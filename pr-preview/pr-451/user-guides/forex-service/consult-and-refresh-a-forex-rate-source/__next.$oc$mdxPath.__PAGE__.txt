# Consult and refresh a forex rate source

Open a market’s rate tables to view stored past and live rates; opening a table triggers a refresh from the external rate service.

## Who can do this?

Users with portal access can view the rate sources. The app is read-only; no role can edit its sources or rate rows here.

## What do I need before I start?

- The market/rate source and rate type you want to inspect.
- An external rate provider configured for that source. The app displays stored values if the provider cannot be reached.

## How do I complete the task?

1. Open **Forex Rates** and choose the market/rate source.
2. Open the relevant rate type under **Rates**.
3. Open **Past Rates** to review dated history or **Live Rates** to see the latest stored value and its update time. Opening either table triggers the refresh attempt.
4. Open **Charts** if you want to view the source’s chart widgets.

## How do I know it worked?

**Past Rates** shows dated observations and **Live Rates** shows the most recently stored value and update time. A new update time indicates the latest fetch was stored; if the provider is unavailable, previously stored rates remain visible.

## What if I can’t complete it?

- If a rate table is empty, reopen it to trigger another fetch. A table that has never had a successful fetch may remain empty.
- If **Charts** is blank, the external chart provider may be unavailable; this does not prevent reviewing rate tables.
- If you need to record your own observation, use [Forex Price Data](/user-guides/forex-price-data); this app does not edit rates.
