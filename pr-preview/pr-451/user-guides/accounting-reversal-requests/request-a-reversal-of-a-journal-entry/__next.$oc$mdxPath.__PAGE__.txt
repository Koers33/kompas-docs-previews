# Request a reversal of a journal entry

Create a pending request to correct a posted journal entry; a different Treasury user must decide on it before the platform creates a reversal entry.

## Who can do this?

You need access to the Accounting Reversal Requests app and the Treasury role. The request records who raised it so another Treasury user can review it independently.

## What do I need before I start?

- The posted journal entry you intend to correct. Confirm that you have selected the right entry before saving; the original journal cannot be changed on the request afterward.
- The correction type and a clear reason for the request.
- If the correction is for a prior period or a regulator restatement, follow the separate accounting-period reopening procedure. This request does not reopen a period.

## How do I complete the task?

1. Open **Accounting Reversal Requests** and select **Create**.
2. Choose a **Reversal Type** that matches the correction you are requesting.
3. In **Original Journal**, use the value help to select the journal entry. Check the displayed journal/deal details and processing date to make sure it is the entry you intend to correct.
4. Enter the **Reason** for the correction. The reason and reversal type are required.
5. Review the request and select **Save**. The app fills in the **Requester** and **Request Date**, and the saved request becomes **Pending**.

## How do I know it worked?

The request appears with **Pending** status, your requester information, the request date, the selected original journal and the reason. Saving the request does not create the reversal journal entry; that happens only after a different user approves it.

## What if I can’t complete it?

- If the request will not save, complete **Reversal Type** and **Reason**, then try again.
- If the journal entry you need is not available in the **Original Journal** value help, confirm that the entry exists in Journal Entries and ask your accounting support contact to resolve missing or incomplete journal data.
- If the correction involves a prior period or regulator restatement, coordinate the separate period-reopening procedure; this app records the request but does not reopen the period.
