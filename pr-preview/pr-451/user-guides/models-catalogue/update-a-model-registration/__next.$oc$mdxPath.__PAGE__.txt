# Update a model registration

Correct a model's name, version or recorded status while preserving its unique model code and governance history.

## Who can do this?

Users with portal access can update registrations. Follow your model-governance process before recording a new version or status.

## What do I need before I start?

- The existing registration and its **Model Code**.
- The approved **Name**, **Version** or **Status** change.
- Confirmation that any change to a later status reflects work completed outside this app; changing the field does not run validation or certification.

## How do I complete the task?

1. Open **Models Catalogue** and find the record by **Model Code**.
2. Open the registration and select **Edit**.
3. Update the model name, version or status as approved. Leave **Model Code** unchanged.
4. Confirm **Registered At** is not in the future, then save and activate the draft using the app's normal save flow.
5. Reopen the record and confirm **General Information** and **Governance** show the intended values and change stamps.

## How do I know it worked?

The registration shows the new name, version or status. Its code remains the same, and the governance section shows the latest change timestamp and user.

## What if I can’t complete it?

- If the app refuses a code change, the **Model Code** is immutable after creation; continue using the existing code.
- If a code conflict appears, the code belongs to another registration; do not create a duplicate.
- If a field is too long or required, shorten or complete the value. **Registered At** cannot be set in the future.
- If the status has changed but validation or certification has not occurred, correct the status after confirming the true stage with the model owner.
