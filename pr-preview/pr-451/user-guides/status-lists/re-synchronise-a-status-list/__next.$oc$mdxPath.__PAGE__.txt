# Re-synchronise a status list

Pull current status values from the live list into its catalogue view, or push reviewed entry changes from the catalogue back to the live list.

## Who can do this?

Users with portal access can refresh and update status-list entries. Follow the status-list owner's change process before pushing values used by business workflows.

## What do I need before I start?

- The **Entity Name** of the status list to synchronise.
- A decision whether you are pulling live values into the view or applying reviewed staged values.
- If pushing, the intended codes, names, descriptions and active states.

## How do I complete the task?

1. Open **Status Lists** and select the status list.
2. To pull current values from the live list, run **Refresh Entries**. This replaces the entries currently shown with the live list's values.
3. To apply the displayed/staged entries to the live list, review them and run **Update Entries**.
4. Reopen the list and confirm the entries reflect the direction you chose.
5. Check the corresponding business app's dropdown when you need to verify the value is available to users.

## How do I know it worked?

After **Refresh Entries**, the catalogue view mirrors the live list. After **Update Entries**, the new or corrected entries are available to the apps that read that status list.

## What if I can’t complete it?

- **Refresh Entries** overwrites the current view with live data; do not run it if you need to preserve staged edits.
- If an update fails for a required code/name or duplicate, correct the entry before updating again.
- Status list definitions cannot be created or deleted here; only values within existing lists are maintained.
