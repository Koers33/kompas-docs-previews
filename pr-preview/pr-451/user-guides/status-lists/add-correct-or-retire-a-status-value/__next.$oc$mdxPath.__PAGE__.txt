# Add, correct or retire a status value

Maintain a value in an existing status list so the correct workflow state is offered in the apps that use it.

## Who can do this?

The app requires portal access and has no additional role restriction. Follow the owner’s approval process because status values can affect workflow and reporting.

## What do I need before I start?

- The status list's **Entity Name** and **Domain Group**.
- The approved status **Code**, **Name** and **Description**.
- Confirmation whether the value should remain active or be retired.

## How do I complete the task?

1. Open **Status Lists**, filter by **Domain Group** and select the status list.
2. In **Status List Entries**, add a value or open an existing entry to correct its name or description.
3. Complete the required **Code** and **Name**. For an existing value, switch **Is Active** off if it should no longer be offered.
4. Save the entry. If you are applying staged rows, select **Update Entries** after reviewing them.
5. Reopen the list and confirm the value and active state.

## How do I know it worked?

The entry appears with its code, name, description and active state. Active values are available in the live dropdowns that use the list.

## What if I can’t complete it?

- If code or name is missing, complete both before saving.
- If the value is already referenced, do not delete it; deactivate it so existing records retain a valid reference.
- If entries look stale, use [Re-synchronise a status list](./re-synchronise-a-status-list) to pull the live list before editing or to push staged entries.

## What should I do next?
