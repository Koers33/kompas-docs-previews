# Maintain risk percentage bands for a client

Add or correct the risk percentage bands used for a specific business partner, or deactivate a band that should no longer be in use.

## Who can do this?

The **Treasury** role is required to read and maintain these records.

## What do I need before I start?

- The **Business Partner** whose project bands need attention.
- The approved **Minimum Percentage**, **Maximum Percentage** and **Risk Percentage** for each band.
- Confirmation that the ranges are consistent with the other bands for that client; the app does not check for gaps or overlaps.

## How do I complete the task?

1. Open **Risk Project Percentages** and filter by **Business Partner**.
2. Review the client's active and inactive rows. If the client has no rows, check whether a first project has been created; the platform copies default bands when that first project is saved.
3. Select **Create** to add a client band, or open an existing client row to correct it.
4. Enter the minimum, maximum and risk percentages, each between 0 and 100. Keep the **Business Partner** set to the intended client.
5. Save and activate the draft. To retire a band, switch **is Active** off instead of deleting it.
6. Reopen the client rows and verify the percentages and active state.

## How do I know it worked?

The client's band appears in the **Active** or **Inactive** view with its business partner and percentage values. The saved risk percentage is available to the project processes that use the client's bands.

## What if I can’t complete it?

- If a percentage is refused, enter a value from 0 to 100.
- If there are no client rows, confirm the client has a project or add the approved client-specific bands. Default rows are a separate view.
- If the range overlaps or leaves a gap, correct the values manually; the app does not validate bands against one another.
- Rows cannot be deleted. Switch **is Active** off to retire a band.

## What should I do next?
