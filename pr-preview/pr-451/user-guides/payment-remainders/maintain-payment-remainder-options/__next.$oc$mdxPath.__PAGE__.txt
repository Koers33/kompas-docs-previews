# Maintain payment remainder options

Add or correct a payment remainder choice, or deactivate an option that should no longer be selected on new records.

## Who can do this?

The app requires portal access and the roles assigned by your administrator. Confirm changes with the owner of payment-request configuration before making a shared option available.

## What do I need before I start?

- A stable **Code** and **Name** for the option.
- Its **Description** and whether it should be **is Active**.
- For an existing option, confirmation that the code is not being repurposed for a different meaning; existing records retain the code they used.

## How do I complete the task?

1. Open **Payment Remainders**. Select **Create** for a new option, or open an existing option to correct its name or description.
2. Enter **Code**, **Name** and **Description**, then set **is Active**.
3. Save and activate the draft using the app's normal save flow.
4. To retire an option, switch **is Active** off and save; do not try to delete it.
5. Reopen the list and verify the code, name, description and active state.

## How do I know it worked?

The option appears in the list with the saved values. Active options are available in records that use the payment remainder choice; inactive ones are retained but no longer offered for new selection.

## What if I can’t complete it?

- If an option is missing from a payment request, add and activate it here, then reopen the consuming record.
- If a code is already used, update the existing option or choose a new code; do not reuse the old code for a different meaning.
- If delete is refused, deactivate the option instead.
