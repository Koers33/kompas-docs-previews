# Add, correct or retire a system codelist value

Maintain a technical platform picklist value used by system configuration, integration or monitoring screens.

## Who can do this?

The app requires portal access and has no narrower role restriction. Confirm a technical-list change with the owning platform team before applying it.

## What do I need before I start?

- The list's **Entity Name** and **Domain Group**.
- The approved **Code**, **Name** and **Description** for the value.
- Confirmation that the list is a system codelist, not a business status list.

## How do I complete the task?

1. Open **System Codelists** and filter or browse by **Domain Group**.
2. Open the list and work in **Codelist Entries**. Add a value or open an existing value to correct its name or description.
3. Enter the required **Code** and **Name**. To retire a value, switch **Is Active** off; do not delete it.
4. Save and, if you are applying staged entries, run **Update Entries** after reviewing the list.
5. Reopen the list and verify the entry and active state.

## How do I know it worked?

The entry appears in **Codelist Entries** with the intended code, name, description and active state. The platform screens that consume the list can then use the active value.

## What if I can’t complete it?

- A code is permanent once saved; update the name or description rather than changing the code.
- Duplicate codes and entries without a code or name are refused.
- If the list row itself is missing, contact the platform administrator; this app cannot create or delete system list definitions.
- For workflow status values, use [Status Lists](/user-guides/status-lists) instead.

## What should I do next?
