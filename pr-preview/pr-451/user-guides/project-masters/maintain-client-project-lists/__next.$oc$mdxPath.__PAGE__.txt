# Maintain client project lists

Add or correct the client-specific options that Projects and Project Items offer for phases, item types, item categories and payment groups.

## Who can do this?

Treasury users can manage project master data. A Client user linked as a **Project Manager** can manage the linked client's lists; a **Project Viewer** can read them only.

## What do I need before I start?

- The client whose project vocabulary needs to change.
- The approved phase category, item type, item category or payment group.
- The required name; **Project Item Types** also require a code and description.

## How do I complete the task?

1. Open **Projects Master Data** and find the existing client record.
2. In the appropriate section, add or edit **Payment Groups**, **Project Phase Categories**, **Project Item Types** or **Project Item Categories**.
3. Enter the required name and, for an item type, its code and description. Keep the row attached to the client record where it belongs.
4. Save the changes. To retire an option, switch its active flag off rather than deleting it.
5. Reopen the section and verify the saved row and active state.

## How do I know it worked?

The row appears under the intended client with its saved values. The option is available in Project Items value helps for that client when active.

## What if I can’t complete it?

- If the client has no **Projects Master Data** record, it cannot be created here; contact the platform administrator to set up the client's master-data row.
- If a required name, item-type code or description is missing, complete it before saving.
- Rows cannot be deleted. Retire an unused option by switching its active flag off.
- If another client's option is missing from a value help, confirm you opened the correct client record; the lists are scoped by client.
