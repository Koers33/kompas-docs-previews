# Documents app

Documents is the platform's file repository. It collects, in one list, files that have been uploaded against projects, business partners, payment requests, project items and project phases, so you can find a document without opening each record it belongs to.

## What is this app for?

Each row is one attachment: its **Document Number**, **Document Classification**, **Document Type**, **File Name**, **Attachment**, **Note** and **Created At**. The classification comes from the platform's four levels — **Public**, **Internal**, **Confidential** and **Strictly Confidential** — and the document type comes from the platform's document-type list (for example an invoice, a purchase order, proof of identity or a trade confirmation).

## When should I use this app?

Use it when you need to locate or check a file that has already been uploaded somewhere in the platform — during client onboarding, while a payment request is being processed, or as part of a project. Uploading, replacing or removing a file is done on the record the file belongs to; this app only reads what is already there.

## Who can access this app?

Reading is decided by role and by record. The service gives the **Treasury** role full access to documents, while a **Client** user reaches documents only where their own account is the client, or where their account holds an active relationship with that client — and documents recorded against FEC Transactions stay outside that client grant. These are service permissions; what you can actually open still depends on the roles assigned to you (see [Roles and Access](/getting-started/roles-and-access)).

## How does work progress in this app?

There is no lifecycle to work through. Filter or pick a table view, open a row, read it, and open the **Attachment** if you need the file itself. Any change to a document happens in the app where the file was uploaded.

## What can change what I see or do?

- **Table views:** the list can be narrowed to one source area — **Projects**, **Business Partners**, **Payment Requests** or **Project Items** — which changes which rows appear.
- **Document Type:** the filter field on the list, and the type shown on each record.
- **Read-only:** the app offers no create, edit or delete for anyone, so an empty action toolbar is expected.
- **Your role and record link:** a client user sees only the scope their account is linked to, so the same list can be shorter for one person than for another.

## Where can I review the results?

Open a row and read the **General Information** section for the document number, classification, type, file name, note and creation date; the **Attachment** field carries the file itself. The list is usually enough to confirm whether a document exists and when it was added.

## What should I check if I can't continue?

- A file you expect is missing: it appears only if it was uploaded to one of the areas this list covers — check the source record and, if nothing is there, upload it in that app.
- The list looks empty: clear the **Document Type** filter or switch back to the **All** table view.
- The app itself does not open: check your access first — see [Roles and Access](/getting-started/roles-and-access).

## Which task guides are available?

No task guide is published for this app yet; finding a document, reading its details and understanding why one is missing are covered on this page.
