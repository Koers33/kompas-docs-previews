# Cost Provision Rates app

Cost Provision Rates is where the cost provision held against a platform action is maintained. Every named action the platform exposes — confirming a deal, closing a period, approving a mapping — has a row here, identified by its **App Code**, **Button Name** and **Button Technical Name**, and each row carries the two editable settings: a **Cost Provision Classification** and a **Cost Provision Value**. When the platform raises a cost provision entry for an action, it copies the classification and value from that action's row.

## What is this app for?

The app keeps those two settings current as the platform's cost provisioning rules change. The rest of the row — **Code**, **Button Name**, **Button Technical Name** and **App Code** — identifies the action and is fixed, so what you are maintaining here is the rate side of each action, not the action itself.

## When should I use this app?

Use it when a classification or value for an action needs to change, or when you want to check what the platform holds for a particular action before reviewing the entries it produced. Use the row's **App Code**, **Button Name** and **Button Technical Name** to identify the action; use the apps themselves to perform the work rather than reading about it here.

## Who can access this app?

The app is reached through portal access plus the roles your administrator has assigned you — see [Roles and Access](/getting-started/roles-and-access). The register applies no role restriction of its own beyond portal access, so everyone who can open the app sees the same rows and the same two editable fields. Rows cannot be added or deleted here — they come with the platform's action register.

## How does work progress in this app?

There is no lifecycle to progress. Open a row, choose the **Cost Provision Classification** from its list, enter the **Cost Provision Value** you want the platform to use for that action, and save. The row is edited as a draft until you save it, so a value you typed and did not save has no effect.

## What can change what I see or do?

- **Only two fields are editable:** **Cost Provision Classification** and **Cost Provision Value**. The code, button name, technical name and app are read-only for everyone.
- **Fixed value list:** the classification is chosen from the platform's classification list rather than typed in.
- **No new rows:** rows cannot be created or deleted in this app, so an action that has no row cannot be given a rate here.
- **Already-created entries:** a cost provision entry stores its own copy of the classification and value, so changing a value on this page does not rewrite entries the platform has already raised.

## Where can I review the results?

Compare this page against the entries it produced: the **Cost Provisions** app holds one entry per raised cost provision, showing the classification, the value, the **Provision Date/Time**, the **Username** and the **Button Code** behind it. The **Button Code** on an entry points back to the row here, so any difference between an entry and the rate you expected is visible from either side.

The list itself is also the quickest check: filter to the action you are investigating and read its classification and value without opening the record.

## What should I check if I can't continue?

- A field will not accept input: only **Cost Provision Classification** and **Cost Provision Value** are editable; everything else is fixed with the action register.
- A row you expect is missing: rows come from the platform's configuration and cannot be added in this app — note the action and its app and raise it with your platform administrator.
- An entry still shows an old value: entries keep the values they were created with; check when the entry was raised against the value set at the time.
- The app itself does not open: check your access first — see [Roles and Access](/getting-started/roles-and-access).

## Which task guides are available?

No task guide is published for this app yet; changing a classification or value and checking the outcome are covered on this page.
