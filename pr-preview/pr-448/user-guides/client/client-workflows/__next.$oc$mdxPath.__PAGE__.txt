# Client Workflows Guide

> **Goal**: Process a client FX request from initial request through internal contract to payment request.
>
> **Prerequisites**: Phase 1 complete (Company active, GL accounts, Nostro accounts, instruments activated).
>
> **Note**: This phase only applies to companies with `Client Business Enabled = true` and `Operating Model = Combined`. For own-book trading only, skip to Phase 3.

---

## Step 2.1 — Create a Client Request

**App**: Requests
**Action**: Create, fill fields, save

The client submits an FX or payment request. This is the starting point for client book deals.

### General Information tab
| Field | Value | Notes |
|-------|-------|-------|
| Client | *(select client BP)* | Must be marked as `isClient = true` |
| Request Type | `FX` | Type of request |
| Request Status | `New` | Auto-set on create |
| Request Date | *(today's date)* | When the request was received |

### Request Details tab
| Field | Value | Notes |
|-------|-------|-------|
| Counterparty | *(select counterparty BP)* | The bank executing the trade |
| Currency Pair | `ZAR/USD` | Buy/sell currencies |
| Notional Amount | `100000.00` | Amount in base currency |
| Value Date | *(future date)* | Settlement date |
| Market | *(select market)* | Forex market |

**After saving**: Note the Request UUID.

---

## Step 2.2 — Create an Internal Contract

**App**: Internal Contracts
**Action**: Create, fill fields, save

Treasury responds to the client request with contract terms.

### General Information tab
| Field | Value | Notes |
|-------|-------|-------|
| Client Request | *(select request from 2.1)* | Links to the original request |
| Client | *(select client BP)* | Same as request |
| Contract Type | `FX Forward` | Type of contract |
| Status | `Draft` | Auto-set on create |

### Contract Terms tab
| Field | Value | Notes |
|-------|-------|-------|
| Notional | `100000.00` | Contract amount |
| Currency | `ZAR` | Base currency |
| Counter Currency | `USD` | Quote currency |
| All-In Rate | `18.5000` | Agreed exchange rate |
| Value Date | *(future date)* | Settlement date |
| Margin Rate | `0.0025` | Client margin |

**After saving**: Note the Internal Contract UUID.

---

## Step 2.3 — Accept the Internal Contract

**App**: Internal Contracts
**Action**: Click "Accept Contract"

Once terms are agreed, treasury accepts the contract.

1. Open the Internal Contract record
2. Click "Accept Contract"
3. Status changes from `Draft` to `Accepted`

---

## Step 2.4 — Create a Payment Request

**App**: Payment Requests
**Action**: Create, fill fields, save

Formalize the payment instruction for the accepted contract.

### General Information tab
| Field | Value | Notes |
|-------|-------|-------|
| Client | *(select client BP)* | Same as contract |
| Internal Contract | *(select contract from 2.2)* | Links to accepted contract |
| Payment Group | `FX Settlement` | Payment category |
| Status | `Draft` | Auto-set on create |

### Payment Details tab
| Field | Value | Notes |
|-------|-------|-------|
| Amount | `100000.00` | Payment amount |
| Currency | `ZAR` | Payment currency |
| Value Date | *(future date)* | When payment is due |
| Counterparty | *(select counterparty BP)* | Receiving party |
| Bank Account | *(select bank account)* | Settlement account |

**After saving**: Note the Payment Request UUID.

---

## Step 2.5 — Send the Payment Request

**App**: Payment Requests
**Action**: Click "Send Request"

Submit the payment request for processing.

1. Open the Payment Request record
2. Click "Send Request"
3. Status changes from `Draft` to `Sent`

**After Phase 2**: The client workflow is complete. The treasury team can now capture a deal in Phase 3 to execute the trade.

---
